# VastraWise — Frontend Application (`rent-wise`)

This is the Next.js 16 (React 19 + Turbopack) frontend dashboard for **VastraWise Rental Manager**.

For complete setup instructions, API documentation, architecture details, and backend configuration, please refer to the main repository README:

👉 **[Main VastraWise Documentation](../README.md)**

## Development Commands

```bash
# Run Next.js dev server
npm run dev

# Build production bundle
npm run build

# Start production server
npm start
```
